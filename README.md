## 🚀 Local Development & Setup

### Prerequisites
- Any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).

### Quick Start
1. **Clone the repository**:
   ```bash
   git clone https://github.com/Ganesh40292/portfolio.git
   cd portfolio
   ```

2. **Run locally**:
   - Double-click [`index.html`](index.html) to open directly in your web browser.
   - *OR* use VS Code Extension **Live Server** or Python HTTP Server (`python -m http.server 5500`) to run at `http://127.0.0.1:5500`.

## 🌐 Deployment to Vercel

This repository includes a [`vercel.json`](vercel.json) file configured for 1-click deployment to Vercel.

1. Push code to GitHub:
   ```bash
   git add .
   git commit -m "Initial portfolio commit"
   git push origin main
   ```
2. Go to **[vercel.com](https://vercel.com)** ➔ Import repository `portfolio` ➔ Click **Deploy**.
3. Live production link generated automatically!
